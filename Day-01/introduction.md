# Day 01: Introduction to Python and Programming

Today I started learning Python from the basics. Before writing programs, I wanted to understand what programming is, how computers understand instructions, and how programming languages work.

## 1. What is Python?

Python is a programming language that helps us communicate with computers and make them perform different tasks.

Python syntax is simple and easy to read compared to many other programming languages.

We can use Python for:
- Web development
- Automation
- Data analysis
- Artificial Intelligence
- Machine Learning

One of the main reasons I chose Python is that it is beginner-friendly and widely used in the AI/ML field.

---

## 2. What is Programming?

Programming means giving instructions to a computer to solve a problem or perform a task.

A computer cannot understand our thoughts directly. We need to give it instructions in a form it can process.

For example, if we want a computer to add two numbers, we must tell it which numbers to add and what to do with the result.

That process is called programming.

---

## 3. What is Coding?

Coding means writing instructions using a programming language.

For example, in Python:

```python
print("Hello, World!")
```

This instruction tells Python to display `Hello, World!` on the screen.

So, coding is one part of programming.

---

## 4. Programming vs Coding

Coding mainly means writing the actual code.

Programming involves the complete process of solving a problem. It includes understanding the problem, planning a solution, writing code, testing it, and fixing errors.

In simple words, coding is writing instructions, while programming is using those instructions to solve problems.

---

## 5. High-Level Languages

High-level languages are designed to make programming easier for humans.

Their syntax is easier to read and understand. We don't need to deal with every hardware detail while writing programs.

Examples:
- Python
- Java
- C++

For example, in Python, we can print a message using just one line:

```python
print("Hello")
```

This is much easier for humans to understand than writing machine instructions.

---

## 6. Low-Level Languages

Low-level languages are closer to the computer's hardware and processor instructions.

They provide less abstraction compared to high-level languages. Understanding and writing them can be more difficult for beginners.

The two main types we discussed are:

1. Machine Language
2. Assembly Language

---

## 7. Machine Language

Machine language is the language of binary instructions, represented using 0s and 1s.

Processors execute machine instructions directly.

For example, machine instructions are represented in binary form:

```text
10101010
11001100
```

These are example binary patterns, not necessarily complete instructions for a particular processor.

Machine language is difficult for humans to read and write because it uses binary instructions.

---

## 8. Assembly Language

Assembly language uses short symbolic instructions instead of writing binary numbers directly.

These symbols are called mnemonics.

Examples:

- MOV – Move data
- ADD – Add values
- SUB – Subtract values

Assembly language is easier to read than machine language, but it is still closely related to the computer's hardware.

An assembler converts assembly language into machine code.

---

## 9. What is a Compiler?

A compiler is a software tool that translates a program written in a programming language into another form of code.

Depending on the language, it may generate machine code or intermediate code.

For example, C programs are commonly compiled into machine code before execution.

A compiler helps the computer execute the instructions in a form it can understand.

---

## 10. What is an Interpreter?

An interpreter is a software tool that processes and executes program instructions during runtime.

Python commonly uses an interpreter-based execution process.

When we run a Python program, Python processes the code and performs the instructions.

In simple words, an interpreter helps us execute our programs.

---

## 11. Statically Typed and Dynamically Typed Languages

Programming languages handle data types in different ways.

### Statically Typed Language

In a statically typed language, types are checked according to the language's rules before the program runs.

Example: Java

```java
int age = 19;
```

Here, `age` is declared as an integer variable.

### Dynamically Typed Language

In a dynamically typed language, the type is associated with the value, and type checking happens during program execution.

Example: Python

```python
age = 19
age = "Hello"
```

In Python, we don't have to declare the variable's type explicitly.

The same variable name can refer to an integer value and later to a string value.
